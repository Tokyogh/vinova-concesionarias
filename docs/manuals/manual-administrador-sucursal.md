# Manual del administrador de sucursal

Supervisión de operación, equipos y datos dentro de una sucursal.

- Tipo: `manual`
- Categoría: `administracion`
- Permiso requerido: `branches.manage`
- Roles específicos: `admin_sucursal, admin_general, superadmin`
- Ruta contextual: `branches:list`

Manual del administrador de sucursal

Objetivo
Coordinar la operación de una sede respetando el alcance de datos y las políticas generales.

Procedimiento recomendado
1. Confirma que los usuarios operativos estén vinculados a la sucursal correcta.
2. Revisa vehículos, inventario, leads, ventas y facturación de la sede.
3. Atiende alertas de stock y tareas pendientes.
4. Escala a administración general los cambios globales o de seguridad.

Controles importantes
• No reasignes datos de otra sucursal sin autorización.
• No concedas roles globales para resolver necesidades locales.

Antes de terminar
□ Equipo asignado correctamente.
□ Pendientes comerciales revisados.
□ Stock crítico atendido.
